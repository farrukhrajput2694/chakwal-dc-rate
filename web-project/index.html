Heads-up on urban coverage. The portal lists Tehsil Chakwal's urban property areas — 2 towns, 10 revenue circles, 118 property areas — but every one of those 118 reports no Khasra number, no Square number, and no land classification. So the urban chain stops at the Property Area: there is no narrower parcel to pick and no Location list to choose from. That is a gap in the portal's own published data, not a fault in this tool. Rural data is complete and unaffected — all 226 mouzas publish classifications, locations and Khasra numbers.

!

This is the offline build. The form, the unit conversion and the DC value arithmetic all run in your browser and are exact. The one thing it cannot do is read the rate from the Punjab e-Stamp portal itself — that needs a small server, because the portal sends no CORS headers and browsers block the reply. Enter a rate below to use the calculator, or run the FastAPI project for live lookups.
